## Cryo Chamber

A migração não foi modificada. O teste existente e uma verificação temporária
com os helpers reais passaram para layouts antigos de 36/37/38 slots, layout
atual e retomada do redimensionamento final. A verificação adicional simulou
inventários e agendamento, incluindo clones de stacks com metadados. Os itens
dos antigos slots 13 e 15 são devolvidos ao mundo; os demais são remapeados.

Contrato confirmado entre BP, script e UI:

| Função | Índices atuais |
| --- | --- |
| Energia / status / progresso do estabilizador | 0 / 1 / 2 |
| Entrada do estabilizador | 3 |
| Grade de resfriamento | 4–12 |
| Displays de água / cryofluid | 13 / 14 |
| Titânio / lápis-lazúli | 15 / 16 |
| Upgrades | 17–20 |
| Status de resfriamento / geração | 21 / 22 |
| Saída do estabilizador | 23 |
| Botões de I/O de itens | 24–29 |
| Botões de I/O de fluidos | 30–35 |

Fluidos: entrada no tanque 0 e saída no tanque 1. Os modos de itens mantêm os
slots correspondentes, sem índices fora de 0–35.
