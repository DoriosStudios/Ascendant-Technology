# Thermal Control System - Progression Guide

This guide explains when and why to build the Thermal Control Module system, and how it fits into your Ascendant Technology progression.

## When to Build

### Early Game (Not Recommended)
❌ **DO NOT build in early game**
- Requires Titanium (mid-game ore)
- Needs Aetherium access
- Requires Cryo Chamber first
- Not useful without H.P.U systems

### Mid Game (First Module) ✅
✅ **Build your first module when:**
- You have built a Cryo Chamber and it's producing Cryofluid
- You're using H.P.U (Hyper Processing Upgrades) on machines
- You notice machines failing or producing degraded outputs
- You have stable Titanium mining and processing
- You've collected basic Aetherium shards

**Typical timeline:** After establishing your first Titanium processing line and before building large H.P.U setups.

### Late Game (Multiple Modules) ⭐
⭐ **Expand your cooling when:**
- Running 3+ machines with H.P.U simultaneously
- Planning to use Overclock Tower systems
- Building large automated factories
- Experiencing frequent machine failures
- Ready to invest in efficiency upgrades

**Typical timeline:** Once you have stable Aetherium production and advanced machine frames.

### End Game (Fully Upgraded Network) 🚀
🚀 **Maximize cooling infrastructure when:**
- Operating 10+ high-speed machines
- Using maximum H.P.U tiers (×4 or higher)
- Running overclock systems continuously
- Building mega-factories
- Optimizing for maximum throughput

**Typical timeline:** After establishing full Aetherium processing and Logic Core manufacturing.

## Why It's Important

### Problem Without Thermal Control
Without proper cooling, high-speed operations suffer from:
- **Reduced efficiency** (-5% to -30% depending on heat)
- **Increased energy costs** (+10% to +25% extra consumption)
- **Recipe failures** (wasted materials)
- **Machine shutdowns** (requires cooldown periods)
- **Output degradation** (lower quality products)

### Benefits With Thermal Control
With proper cooling in place:
- ✅ **Reliable operations** at high speeds
- ✅ **Consistent output quality** from recipes
- ✅ **Safe H.P.U usage** without failures
- ✅ **Lower total energy costs** (more efficient operations)
- ✅ **Enables scaling** to larger factory setups

### Return on Investment
- **Initial cost:** ~20 Titanium ingots + 3 Aetherium shards
- **Operational cost:** 50-500 mB Cryofluid per operation + 800 DE/tick
- **Benefit:** Enables 2-4× speed safely, prevents 10-30% efficiency loss
- **Break-even:** After ~100 operations at H.P.U ×4
- **Long-term value:** Essential for end-game automation

## Integration with Other Systems

### Cryo Chamber (Prerequisite)
- **Relationship:** Produces Cryofluid consumed by Thermal Control
- **Scaling:** 1 Cryo Chamber can supply 4-6 Thermal Control Modules
- **Tip:** Build multiple Cryo Chambers or use large fluid storage

### Hyper Processing Upgrades (Primary Use Case)
- **Relationship:** H.P.U generates heat, Thermal Control removes it
- **Scaling:** Higher H.P.U tiers = more cooling needed
- **Tip:** Always pair H.P.U tier 3+ with Thermal Control

### Network Center (Monitoring)
- **Relationship:** Network Center monitors cooling effectiveness
- **Information:** Shows consumption, efficiency, machine status
- **Tip:** Use Network Center to identify cooling bottlenecks

### Overclock Tower (Advanced)
- **Relationship:** Overclock generates massive heat, requires cooling
- **Scaling:** Overclock setups need multiple Thermal Control Modules
- **Tip:** Plan cooling infrastructure before activating overclock

### Redundancy Nodes (Future)
- **Relationship:** Will coordinate with Thermal Control for failure recovery
- **Benefits:** Automatic heat management, backup cooling
- **Status:** Planned for future update

## Common Mistakes to Avoid

### ❌ Building Too Early
**Problem:** Wasting resources before you actually need cooling  
**Solution:** Wait until you're using H.P.U tier 2+ regularly

### ❌ Insufficient Cryofluid Supply
**Problem:** Modules running in passive mode only (10% vs 40% cooling)  
**Solution:** Build adequate Cryo Chamber capacity first

### ❌ Poor Placement
**Problem:** Modules not adjacent to machines, no cooling effect  
**Solution:** Place directly touching machines (or use Range Extension)

### ❌ No Energy Connection
**Problem:** Modules in passive mode due to no power  
**Solution:** Connect to energy network with sufficient capacity

### ❌ Ignoring Upgrades
**Problem:** High operational costs, inefficient cooling  
**Solution:** Prioritize Efficiency upgrades for ROI

### ❌ Over-Building
**Problem:** Too many modules for actual needs  
**Solution:** Start with 1-2 modules, expand based on actual heat issues

## Optimization Tips

### Best Practices
1. **Start Small:** One module for testing, expand as needed
2. **Monitor First:** Use one module to understand consumption patterns
3. **Upgrade Smart:** Efficiency upgrades pay for themselves fastest
4. **Plan Layout:** Cluster machines to minimize modules needed
5. **Automate Delivery:** Setup automated Cryofluid capsule delivery

### Resource Management
- **Cryofluid buffer:** Keep 32,000+ mB reserve for sustained operations
- **Energy reserves:** Ensure 10+ MDE capacity for cooling network
- **Spare modules:** Keep materials for 1-2 emergency modules
- **Upgrade path:** Efficiency → Range → Auto-Priority

### Factory Layout
- **Compact clusters:** Group 3-4 machines per module
- **Central cooling:** Place module in center of machine cluster
- **Fluid routing:** Keep Cryofluid lines short and direct
- **Energy grid:** Ensure adequate power distribution
