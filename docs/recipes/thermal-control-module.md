# Thermal Control Module - Recipes

This document contains all crafting recipes related to the Thermal Control Module system.

## Main Module

### Thermal Control Module
**Type:** Crafting Table Recipe  
**Output:** 1× Thermal Control Module

**Ingredients:**
- 4× Titanium Plate
- 2× Aetherium Shard
- 1× Advanced Machine Frame
- 1× Heat Sink
- 2× Reinforced Casing

**Notes:**
- Requires mid-game progression (Titanium + Aetherium access)
- Advanced Machine Frame can be crafted or obtained from machine disassembly
- Heat Sink is a sub-component (see below)

---

## Sub-Components

### Heat Sink
**Type:** Crafting Table Recipe  
**Output:** 1× Heat Sink

**Ingredients:**
- 3× Titanium Ingot
- 4× Copper Ingot
- 1× Cryofluid Capsule (returned empty after crafting)

**Notes:**
- The Cryofluid Capsule is used as a catalyst and returned empty
- Copper can be obtained from vanilla Minecraft mining
- Titanium must be mined and processed in Ascendant Technology

### Reinforced Casing
**Type:** Crafting Table Recipe  
**Output:** 4× Reinforced Casing

**Ingredients:**
- 4× Titanium Plate
- 4× Iron Plate
- 1× Aetherium Shard

**Notes:**
- Produces 4 casings per craft
- Can be used in other advanced machinery recipes
- Titanium Plates must be crafted from Titanium Ingots

## Upgrade Modules

### Efficiency Upgrade
**Type:** Crafting Table Recipe  
**Output:** 1× Thermal Efficiency Upgrade

**Ingredients:**
- 2× Titanium Plate
- 1× Aetherium Shard
- 1× Energy Circuit
- 1× Heat Conductor Coil

**Effects:**
- Reduces Cryofluid consumption by 20%
- Reduces energy consumption by 15%
- Can stack up to 3 times in one module

### Range Extension Upgrade
**Type:** Crafting Table Recipe  
**Output:** 1× Range Extension Upgrade

**Ingredients:**
- 1× Advanced Machine Frame
- 2× Aetherium Shard
- 1× Signal Conduit
- 2× Thermal Plating

**Effects:**
- Tier 1: Extends cooling to diagonal adjacent blocks
- Tier 2: Extends cooling to 2-block radius
- Can stack up to 2 times in one module

### Auto-Priority Upgrade
**Type:** Crafting Table Recipe  
**Output:** 1× Auto-Priority Upgrade

**Ingredients:**
- 1× Processing Unit
- 1× Refined Aetherium Shard
- 1× Logic Core
- 2× Signal Router

**Effects:**
- Automatically prioritizes machines with highest heat
- Balances Cryofluid distribution intelligently
- Reduces total cooling overhead by 10%
- Single-tier upgrade (does not stack)

## Progression Requirements

### Early Requirements
To begin crafting Thermal Control Module components, you need:
- Access to Titanium ore and processing
- Basic Aetherium collection
- Copper mining (vanilla)
- Iron mining and processing (vanilla)

### Mid-Game Requirements
To craft the full module, you need:
- Cryo Chamber operational (for Cryofluid)
- Advanced Machine Frame access
- Stable Titanium production
- Aetherium Shard processing

### Late-Game Requirements
To craft all upgrades, you need:
- Processing Unit manufacturing
- Refined Aetherium production
- Logic Core crafting capability
- Stable resource pipelines

---

## Crafting Order Recommendation

1. **First Priority:** Heat Sink and Reinforced Casing sub-components
2. **Second Priority:** Thermal Control Module itself
3. **Third Priority:** Efficiency Upgrade (most cost-effective)
4. **Fourth Priority:** Range Extension Upgrade (for large setups)
5. **Fifth Priority:** Auto-Priority Upgrade (for automation)

## Recipe Costs Summary

### Total Materials for Basic Module
- Titanium: 19 ingots (4 plates + heat sink + casings)
- Aetherium: 3 shards (2 module + 1 casing)
- Copper: 4 ingots (heat sink)
- Iron: 4 plates (casings)
- Advanced Machine Frame: 1
- Cryofluid Capsule: 1 (catalyst, returned)

### Total Materials for Fully Upgraded Module
Add to basic module:
- Titanium: +12 plates (efficiency + range upgrades)
- Aetherium: +5 shards (3 efficiency + 2 range + auto)
- Copper: +12 ingots (coils + conduits)
- Processing Units: 2
- Logic Core: 1
- Advanced Frames: +1 (range)
- Various electronic components

---

## Tips for Efficient Crafting

1. **Batch Titanium Plates:** Always craft in bulk since many recipes need them
2. **Setup Cryofluid Production:** Get Cryo Chamber running before building modules
3. **Stockpile Heat Conductor Coils:** Used in multiple recipes, craft extra
4. **Plan Upgrade Path:** Start with Efficiency upgrades for best ROI
5. **Use Specialized Machines:** Some components craft faster in dedicated machines
