# Steam rework and Alchemical Station — implementation for the next update

Implemented on 2026-10-29 in the existing working checkout. Manifests, RP format
and addon config remain unchanged at the current version. No commit or push.
Earlier inventory/selection, localization, crop, tool and recipe-book changes are
preserved. No shared UtilityCraft/Core implementation was edited.

## Steam

- New IDs: `utilitycraft:steam_boiler` and `utilitycraft:vaporizer`.
- Basic electric boiler: water only, 128 kDE, two upgrades, 32,000 mB tanks,
  1000 mB water → 1000 mB steam, 2400 DE / 160 ticks.
- Advanced electric vaporizer: 1.024 MDE, four upgrades, 128,000 mB tanks;
  water 1600 DE / 80 ticks; existing Cryofluid and Saline Coolant recipes retained.
- Crafting progression uses Basic Chips/Blast Furnace for Boiler and Advanced
  Chips/Boiler for Vaporizer. Workbench and Assembler patterns match.
- Block definitions, shared runtime, upgrade/duplication profiles, UI routing,
  recipe books, creative catalogue and localization are integrated. Dedicated Boiler/Vaporizer atlases are wired to both block states and I/O; names/help for new content use EN fallback outside PT.
- Existing 31-slot contract and I/O indices retained. Boiler hides/blocks unused
  upgrade cells 7–8 and fixes its input tank to water.
- Legacy Vaporworks remains functional with its capacities and migration. Only
  acquisition is retired; its original recipe is archived outside BP. No forced
  conversion of placed blocks or saved inventories/resources.
- Old custom recipe event retained; new Vaporizer event aliases the same registry.
- Fixed an empty-tank gas-type conflict. Stored gas still prevents changing to an
  incompatible output; a drained tank can select the next recipe's gas.
- Arc-Press Forge steam ID, bonus and consumption remain unchanged.
